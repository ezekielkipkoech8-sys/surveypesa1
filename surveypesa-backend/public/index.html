SurveyPesa HashBack backend

This service powers the M-Pesa STK Push activation payments (Ksh 99 / 149 / 199) for surveypesa.co.ke. There is nothing to see here — the store front lives on the main site.

  • POST /api/stk/initiate — start an STK push
  • GET /api/stk/status/:reference — poll an order's status
  • POST /api/webhook/hashpay — HashPay payment webhook
